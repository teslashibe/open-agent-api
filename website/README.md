# Open Agent API docs

Docusaurus site for install, auth, Cursor BYOK, models, Codex account usage/redemption, and contribution notes.

```bash
npm install
npm start          # http://localhost:3000
npm run build      # static output in build/
```

Content lives in `docs/`. Keep the [model catalog](docs/models/catalog.md) aligned with `../internal/openai/models.go`.
